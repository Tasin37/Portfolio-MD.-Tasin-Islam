# Personal Portfolio Website

A clean, responsive, and modern personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Sections for About, Projects, Resume, and Contact
- Smooth scrolling and subtle animations
- Premium hover effects and polished UI
- Links to resume PDF, GitHub, LinkedIn, and project demos

## Project Files
- `index.html` - Main structure of the portfolio
- `styles.css` - Styling, animations, and responsive design
- `script.js` - Mobile navigation and reveal-on-scroll effects
- `IMG_3289.JPG` - Profile image
- `MD. TASIN ISLAM_CV.pdf` - Resume PDF

## Preview Locally
Open `index.html` directly in a browser, or use a simple local server:

```bash
python -m http.server 3000
```

Then visit:

```text
http://127.0.0.1:3000/
```
